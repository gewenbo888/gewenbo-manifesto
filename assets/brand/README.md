# 繁星会 · 标志与资源

组织全称：繁星永恒会。简称：繁星会。既有品牌与域名标识：Psyverse。创始纲领：《源代码》。

## 标志理念

**人人都能成为星。**

标志以 ψ 为形，承载 Psy 的精神意涵，也像一个舒展双臂的人。在《源代码》的精神与宗旨指引下，每个人都可以求索、创造，成为一颗星，共同实现繁星永恒。

这是繁星会赋予标志的品牌解释。

## 完整使命

用科学、技术和工程，解决真实的问题，满足人们的需求，创造新的可能和趋势。

## 使用

主色：松绿 #244C40。浅底：#F4F6F5。
保持比例，不拉伸、不旋转、不加阴影，不将圆点与中轴重新连接。
独立标志最小建议尺寸为 20px；16px 使用 favicon。
四周留白至少为标志宽度的四分之一。深色背景使用反白版。
