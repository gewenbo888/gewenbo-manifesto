# Psyverse · 源点

以 ψ 为骨架：独立的源点、向两侧展开的曲线与向下延伸的中轴。单色几何构形，用于 Psyverse 网站与品牌识别。

- 主色：松绿 #244C40；浅底 #F4F6F3。
- psyverse-mark.svg：独立符号，透明背景；black / white 用于单色应用。
- psyverse-lockup.svg：符号与 PSYVERSE 横向组合，文字依赖 Avenir Next / Helvetica Neue / Arial。
- favicon.svg：小尺寸专用深底反白图标。
- 最小尺寸：独立符号 20px；16px 使用 favicon。
- 留白：符号左右至少保留自身宽度的四分之一。
- 不拉伸、不加阴影、不旋转，不将源点与中轴重新连接。


## 组织与纲领

组织全称为「繁星永恒会」，简称「繁星会」。Psyverse 保留为既有品牌与域名标识；《源代码》为创始纲领，使命完整保留解决真实问题、满足人们需求、创造新的可能和趋势三个层次。
